# Focusly — Todo list responsive

Une interface de gestion de tâches moderne, créée en HTML, CSS et JavaScript vanilla.

## Fonctionnalités

- Ajout, édition, suppression et validation des tâches
- Catégories Travail, Personnel, Courses et Santé
- Filtres Aujourd'hui, À venir et Terminées
- Progression quotidienne calculée automatiquement
- Thème sombre mémorisé et données persistantes avec `localStorage`
- Mise en page responsive pour ordinateur, tablette et mobile

## Lancer le projet

Ouvrez simplement `index.html` dans un navigateur web. Aucune installation n'est nécessaire.

## Structure

```
index.html  # Structure de la page
style.css   # Design, variables et responsive
main.js     # Interactions et stockage local
```
